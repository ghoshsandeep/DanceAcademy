# Image assets

Drop real photographs into this folder using these exact filenames and the site
will pick them up automatically — no code changes needed.

| Filename              | Used for                                   | Suggested aspect ratio |
|-----------------------|---------------------------------------------|-------------------------|
| `suji-hero.jpg`        | Homepage hero image                         | 4:5 (portrait)          |
| `suji-portrait.jpg`    | "Meet Suji" section                         | 4:5 (portrait)          |
| `suji-performance.jpg` | Achievements / tradition section            | 4:5 or 1:1              |
| `suji-teaching.jpg`    | Academy / teaching approach section         | 4:5 or 1:1              |
| `gallery-01.jpg` … `gallery-06.jpg` | "In Motion" gallery carousel   | 1:1 or 4:5               |
| `students-01.jpg`      | Gallery / students in class                 | 1:1 or 4:5               |
| `workshop-01.jpg`      | Gallery / workshop activity                 | 1:1 or 4:5               |

Until real photography is supplied, the site renders elegant placeholder
tiles (see `src/data/media.ts`) so no broken images ever appear.
